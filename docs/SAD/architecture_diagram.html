SYSTEM ARCHITECTURE · DISTRIBUTED ATS PLATFORM

Smart ATS Platform Architecture

Production topology featuring Next.js 16 App Router, FastAPI 0.141.1 Gateway, Celery 5.6.3 + LangGraph 1.2.12 Agentic Loop, PostgreSQL 18.x with Row-Level Security, Redis 8.10.2 SSE Broker, and S3 Object Store.

SECURITY ARCHITECTURE

Multi-Tenant Row-Level Security

  • PostgreSQL 18 RLS: Dynamic session variable SET LOCAL app.current_tenant configured per HTTP transaction by FastAPI middleware.
  • Zero Cross-Tenant Leakage: Enforced at the SQL engine level; rogue application queries cannot access unauthorized tenant partitions.
  • Role-Based Access: Strict permission checks for Recruiter, Company Admin, and System Admin roles.

AGENTIC ENGINE

LangGraph 1.2.12 Reflection Loop

  • Autonomous Campaign Workflow: StateGraph executes Plan → Execute Tools → Reflect loop with maximum 2 iterations.
  • Human-in-the-Loop (HITL): Halts and requests recruiter confirmation before destructive actions or ambiguous job matching.
  • Explainable Fit-Gap: Synthesizes structured JSON scoring with STAR interview question generation.

HIGH SCALE & STREAMING

Distributed Streaming Pipeline

  • SSE Live Token Stream: Redis Pub/Sub channels push real-time agent thoughts directly to Next.js UI via Server-Sent Events.
  • Celery 5.6.3 Concurrency: Decouples heavy AI inference and document parsing from user-facing API threads.
  • Direct S3 Presigned Uploads: Browsers upload multi-megabyte CVs straight to encrypted S3 buckets, bypassing web servers.
